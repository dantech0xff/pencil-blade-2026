## Question 01 — Where does each recovered rule live?

The clean-room boundary is architectural, not rhetorical. A rule must have a pure owner, an
engine adapter only where needed, deterministic verification, and a disclosed limit.

### Artifact

Reviewed contracts define world units, timing, input, score, persistence, presentation, audio,
and mode lifecycle. The native symbol surface names six modes but supplies no production source
tree. The reconstruction therefore uses **Cocos Creator 3.8.8 + TypeScript** as a new
implementation boundary.

### Method

Pure domain modules own deterministic rules and state. Creator adapters alone own
Physics2D, scene nodes, audio, resources, storage, and lifecycle. Creator public gravity
`(0,-320)` world units/s² represents the recovered `(0,-10) m/s²` through PTM **32**. The
manual step remains `frameDt * worldSpeed` with **10/10** iterations. Blade queries remain
forward then reverse, and lifecycle destruction remains deferred.

### Contract or decision

Shared orchestration owns one active screen, input and Physics2D leases, presentation roots,
audio boundaries, and process-owned settings. Mode-specific owners activate only after a
transaction commits:

1. **Classic** — untimed nine-controller graph and standard blade.
2. **Crazy** — 60-second special/bomb graph.
3. **Gangnam Style** — independent 150-second ordinary-fruit graph and dedicated music.
4. **Classic Bird** — Classic-family session with BirdBlade type 1.
5. **Crazy Bird** — Crazy profile with BirdBlade type 2.
6. **Combo Bird** — independent 90-second ordinary-only graph with BirdBlade type 3.

### Proof

All six production route IDs `0` through `5` are live. Contract tests cover route ownership,
fresh retry/replay/menu transactions, input and physics leases, presentation, audio, settings,
and scene composition. The representative blade trace remains mapped to domain files,
Creator adapters, deterministic tests, and the backend probe.

### Limit

The implementation does not ingest, link, emulate, or mechanically translate the APK,
`libgame.so`, Cocos2d-x application runtime, or decompiler output. Type-safe Creator contact
handling deliberately does not reproduce a recovered memory-unsafe native layout.

## Question 02 — What does “100%” mean here?

It means conformance to one frozen, versioned recovered-contract metric—not perfect history and
not a visual comparison with an unavailable original.

### Artifact

**761 consumed**, **100 reviewed excluded**, **1 unsupported**, and **0 unknown
dispositions**. Exact-byte staging and Creator metadata close **862/862**, while commercial
