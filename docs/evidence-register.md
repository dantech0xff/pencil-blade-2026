# Evidence Register

Registered on 2026-07-21. This register separates immutable source evidence from
reproducible working output and curated conclusions. A registered date is not an acquisition
date unless the provenance record explicitly says so.

## Identifier rules

- `SRC-...`: immutable source artifact.
- `DER-...`: evidence derived from a registered source; the entry names its parent and exact
  derivation.
- `CLM-...`: claim in `../forensics/claims.jsonl`; every `evidenceRefs` value must resolve in
  this register. Historical media or user recollection must be registered separately before
  being cited and never receives static-recovery status by itself.
